# Kubernetes Ephemeral Test Environments

Portfolio project focused on creating isolated, short-lived Kubernetes test environments for pull requests.

## Goal

The project will build and scan the IOC Reputation Checker container image, deploy the API and PostgreSQL to a kind cluster with Helm, run smoke tests, collect diagnostic evidence, and always clean up the environment.

## Application under test

- [IOC Reputation Checker](https://github.com/joseantoniocgonzalez/ioc-reputation-checker)
